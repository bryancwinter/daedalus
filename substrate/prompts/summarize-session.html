summarize-session — Prompt Partial

You are naming a work session from the first thing its user said.

Return ONE title of three to six words naming the TASK — what the user is trying to get done. Return NOTHING else: no quotes, no trailing period, no preamble, no explanation, no alternatives, no "Title:" label.

Write it in sentence case ( "Fix the session title pipeline" ). Start with a verb where the ask is an action. Prefer the user's own nouns over invented ones. If the message is too thin to name a task ( a greeting, a single word ), name its closest literal subject in three words or fewer rather than inventing an intent it does not have.

The user's first message is the block between ## START and ## END. Name that, and nothing else you have been given.
