Close — Contract

Work finishes whether or not its habits ever fired. Close is the sweep that makes sure they did, for the tasks being closed.

When

Invoked explicitly as #close, or by description — "let's wrap up", "close this out", "we're done with that". It closes a TASK or a group of tasks: everything done since the previous close, or the tasks the human names. It is often the last command of a session, and it does not end one. Run it while the context that knows what happened is still loaded.

Habits fire on triggers, and work that never hit a trigger still finishes. Close is the sweep over the duties those habits own. It routes to each habit rather than restating it, so when a habit changes, close does not.

The friction is the point. Agentic work moves faster than it can be checked, and close is one of the deliberate stops where output is validated and the human is brought back into the loop before the context that produced it is gone.

Lifecycle

Six phases, in order. Each ends with a one-line report to the human, including when there was nothing to do — a phase that skips silently cannot be told apart from a phase that was forgotten.

Phase 1 — Todos

Trigger: always.

Together: The session files every deferred item, open decision or pending dependency the closed tasks surfaced and did not record, per the active lens's track-todo habit. It clears from the todo list every item the closed tasks actually finished — the completed log, not the todo list, is where done work is recorded. The human rules on any item whose status is a judgment rather than a fact.

Standard: Nothing the closed tasks surfaced exists only in the transcript. An item is cleared because the work landed, not because it was discussed.

Phase 2 — Completed log

Trigger: a closed task substantially advanced a lens's work.

Together: The record is by task, not by session: one entry per task or coherent group of tasks, filed under the lens it advanced, per the log-completed habit.

Standard: The entry says what was done, why, and what it unlocks. A trivial or exploratory task writes none and says so.

Phase 3 — Action log entry

Trigger: the closed tasks changed anything under _Claude/.

Together: One entry, per whichever pole of the log-action class this session is wearing. The slot is named, never an occupant — a contract that hard-linked one pole would be wrong for every session carrying a different one.

Standard: Exactly one breadcrumb per close, however much it covers — only what came after the previous close.

Phase 4 — Vault health

Trigger: the closed tasks wrote, moved or deleted any KCD artifact.

Together: The session runs sm_documentation__validate_docs on each artifact it wrote, and on the whole vault if anything was moved or deleted. A failure the closed tasks introduced is fixed now. A failure that predates them is surfaced to the human and left alone.

Standard: sm_documentation__validate_docs is believed over the session's own reading. The session leaves behind no failure of its own making.

Phase 5 — Scratch

Trigger: the closed tasks wrote any byproduct — scratch, AI notes, dumps, one-off scripts — under its lens's work area or anywhere else it put one.

Together: The session lists each byproduct with one line on what it is, then deletes it. Scratch is not kept: a byproduct left behind outlives the context that explains it and confuses whoever finds it next. Nothing is deleted before it has been described, and only the session's own — another lane's scratch is not this session's to delete. A byproduct survives only when the human has asked to keep it. Close only names a promotion candidate, before its source is deleted — moving an artifact into canonical documentation is owned by the plan contract's retirement.

Standard: The session leaves no byproduct of its own behind. Every one is described, then gone, unless the human kept it by name.

Phase 6 — Handoff

Trigger: always.

Together: The session writes the human a short prose handoff: what landed, what is half-done and where it stands, which plan it advanced if any, and what the next session must be told that nothing on disk records. The handoff is the last step — nothing waits on a further confirmation.

Standard: The handoff is prose to the human, not a file. Anything in it that must outlive the conversation belongs in a todo or a plan — send it back through Phase 1.

Standards

  • Route, never restate. Each phase names the habit or contract that owns its format. The format lives there; close carries only order and trigger.
  • The session's own habit poles govern. Where a lens brings in a different pole — log-action-never, say — that phase reports it is off and moves on. Close never overrides a slot.
  • Invoking close is the confirmation. #close authorizes the whole sweep; the session does not ask whether the work, or the session, is closed. It stops only for a genuine ruling inside a phase — whether an item is really done, whether to keep a byproduct — and where the human is not there to rule, that item is filed as a todo rather than asked about. Silence is not consent, and neither is an approval given earlier for something else.
  • Plans are not close's. A plan's state, checkboxes and retirement belong to the plan contract. Close names the plan in the handoff; invoking the plan contract is a separate decision.
  • Git is not close's. Close never stages, commits or reports on version control. That is the human's safe copy, and it stays in the human's hands.

Edge Cases

  • Invoked mid-session. The ordinary case. Run it in full on the tasks being closed; the session carries on afterwards. Close closes work, not sessions.
  • Several lanes open at once. Each session closes only its own work. A todo, log line or scratch file another lane wrote is not this session's to rule on.
  • Context already compacted. What the session can no longer see, it says it can no longer see. It never reconstructs a record from a summary and files it as fact.

Scope Values

universal — referenced from _lens-base, so work under any lens can be closed.
